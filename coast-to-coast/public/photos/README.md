# Photos — drop your real roof photos here

The site looks for the files below. **Until a file exists, that spot shows a
rooftop illustration** (never a broken image), so you can add photos whenever.

## How to add them (no coding)
1. Save your best real job photos (from your phone or Facebook).
2. Rename each to the exact name below.
3. On GitHub, open `coast-to-coast/public/photos` → **Add file ▸ Upload files** → drag them in → **Commit changes**.

`.jpg`, `.jpeg`, `.png`, and `.webp` all work.

| Filename        | Where it shows              |
| --------------- | --------------------------- |
| `hero.jpg`      | Big hero + page banners     |
| `project-1.jpg` | Home + Projects             |
| `project-2.jpg` | Home + Projects             |
| `project-3.jpg` | Home + Projects             |
| `project-4.jpg` | Projects                    |
| `project-5.jpg` | Projects                    |
| `project-6.jpg` | Projects                    |

Tip: wide (landscape) photos of finished roofs in good daylight look best.
